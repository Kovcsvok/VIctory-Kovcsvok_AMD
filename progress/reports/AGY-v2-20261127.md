## 3. 20 fps and indoor RT fixes (`ebd4988`)

1. **`VICTORY_CARD_STEPS_LEARN` off by default (`crates/victory-gpu/src/host/card_steps.rs`)**:
   - `late::on()`'s default branch became `.is_some_and(|v| v == "1")` (`crate::ab::pick("VICTORY_CARD_STEPS_LEARN")` kept).
   - So `VICTORY_PORT_CBV_WRITTEN=2` stays active by default without the card re-learning holding back the frame rate with a submission wait (stall).
   - `agy-v2-profil.ps1`: `$env:VICTORY_CARD_STEPS_LEARN = '0'`.

2. **`VICTORY_BVH_NO_HIT` and releasing `CS_ScreenProbes_ActivateRays`**:
   - `crates/victory-shader/src/emit/intersect.rs`: the `no_hit()` / `TEST_NO_HIT` mechanism ported. In non-test builds it is **ON** by default if `VICTORY_BVH_BUILDER != "1"` (unless `VICTORY_BVH_NO_HIT=0`; always ON with `VICTORY_BVH_NO_HIT=1`).
   - `Lower::bvh()` returns right away before node memory reads: for a box node (`(pointer & 6) == 4`) with `0xffff_ffff`, for a triangle with `bvh::MISS` (`[+inf, 1.0, 0.0, 0.0]`), without touching the `ray` or the memory library (`self.memory`).
   - `crates/victory-shader/src/emit/intersect_tests.rs`: added the `a_node_test_that_answers_no_hit_reads_nothing` unit test.
   - `crates/victory-shader/src/lib.rs`: `TRANSLATOR_VERSION` `3` → **`4`**.
   - `crates/victory-gpu/src/shader_cache.rs::build()`: `VICTORY_BVH_NO_HIT` and `VICTORY_BVH_BUILDER` added to the compile cache key.
   - `crates/victory-gpu/src/pipeline.rs`: `skip_activate_rays()` (`VICTORY_SKIP_ACTIVATE_RAYS=1`) added; by default `CS_ScreenProbes_ActivateRays` is **not** skipped when `VICTORY_BVH_NO_HIT` is active.

3. **Indoor `Role::Reflect` (`hold_reflect`) and an `execute_indirect` ambient hook**:
   - `crates/victory-gpu/src/ambient.rs`:
     * Kept `agy-9070-v2`'s `stats` (`UAV(u3)`) buffer and the `words[11] = u32::from(crate::lightprobe::on())` binding.
