## 2. Built: an unattended run pair for a setting fixed at start

**`meresek\eszkozok\kartya-par.ps1`**
- Runs `meres-csomag.ps1` 2 × `Parok` times in ABBA order:
  - A: the bundle as it is;
  - B: `VICTORY_CARD_BUFFERS_MIN_MB=<MinMb>`, default 1.
- Each run: `-TexMax 512 -LookMs 250 -AutoA 25,100,5 -Perc <Perc>`, default 12.
- It writes `kartya-par.txt` into each run folder, restores the variable afterwards, and runs the comparer.
- It stops when a run is refused (exit 2) or leaves no folder.
- `-Probe` only prints the commands.
- Default length: 4 × ~13 min ≈ 55 min, unattended, PC not in use.

**`meresek\eszkozok\futas-osszevetes.py`**
- Per run: mean, median and p90 ms/frame, plus mean draws/frame, from second 180.
- Per label: pooled.
- Then a draw-matched difference: bins of 500 draws a frame, B minus A, weighted.

**Checks**
- PowerShell parse: 0 errors.
- `-Probe`: four commands as intended, and the variable is unset afterwards.
- Comparer on `232537-ebresztes-ab` (A) and `234340-keso-kartya-ab` (B):
  - A: 43.6 ms at 7,082 draws;
  - B: 42.3 ms at 4,420 draws;
  - **no 500-draw bin has 5 lines in both.**

So two runs at the same save can land in scenes of different load, and a plain mean compares scenes, not settings. ABBA with four runs gives the bins a chance to overlap. If they still do not, the run pair needs a fixed scene, not just the same save.
